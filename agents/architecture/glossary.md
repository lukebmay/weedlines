# Glossary

When to use: A product word you are about to write.

**Owner:** human. Agents may propose edits; apply only with explicit
permission.

A row names a word and points at the part that rules it. The part
holds the rule. This file does not restate it. Handbook words stay
in [`../glossary.md`](../glossary.md).

| Word | Meaning |
| --- | --- |
| **figure** | One border from one path element, after twins are collapsed. [`preflight.md`](./preflight.md) |
| **positive figure** | A figure whose interior is subject. [`algorithms.md`](./algorithms.md) |
| **negative figure** | A figure whose interior is weed. [`algorithms.md`](./algorithms.md) |
| **composite** | What a join makes. Not a figure. [`algorithms.md`](./algorithms.md) |
| **enclosed figure** | A figure whose border is fully connected. [`preflight.md`](./preflight.md) |
| **unenclosed figure** | A figure with at least one dangling end. [`preflight.md`](./preflight.md) |
| **dangling end** | An endpoint of a figure that meets no other endpoint of that figure. [`preflight.md`](./preflight.md) |
| **twin** | A second copy of the same outline. It is not a second figure. [`preflight.md`](./preflight.md) |
| **nesting** | One figure's interior lies inside another and their outlines do not cross. [`preflight.md`](./preflight.md) |
| **separate-figure overlap** | An overlap of two figures. [`preflight.md`](./preflight.md) |
| **self-overlap** | An overlap of one figure. [`preflight.md`](./preflight.md) |
| **figure check** | The library's three defect detections. [`preflight.md`](./preflight.md) |
| **subject** | The region the person keeps. Solvers call this keep. [`preview.md`](./preview.md) |
| **piece** | The subject, taken as one. [`algorithms.md`](./algorithms.md) |
| **piece size** | The axis-aligned rectangle of the piece. [`algorithms.md`](./algorithms.md) |
| **weed area** | The region a weed line may cut. Solvers call this waste. [`preview.md`](./preview.md) |
| **swap** | The window action that exchanges subject and weed area. [`preview.md`](./preview.md) |
| **plugin setting** | A window control that changes a preview color. [`preview.md`](./preview.md) |
| **correction arrow** | A straight arrow from a corner of the design to one defect. [`preview.md`](./preview.md) |
| **dangling arrow** | The correction arrow for a dangling end. [`preview.md`](./preview.md) |
| **overlap arrow** | The correction arrow for a separate-figure overlap. [`preview.md`](./preview.md) |
| **self-overlap arrow** | The correction arrow for a self-overlap. [`preview.md`](./preview.md) |
| **weed line** | A cut an algorithm emits in the weed area. [`algorithms.md`](./algorithms.md) |
| **cavern** | A concavity in the coastline of a weed area. [`algorithms.md`](./algorithms.md) |
| **bay** | A cavern. Not a second coastline object. [`algorithms.md`](./algorithms.md) |
| **sheet** | Waste wider than the sheet threshold. [`algorithms.md`](./algorithms.md) |
| **sheet threshold** | The diameter that marks a sheet. [`algorithms.md`](./algorithms.md) |
| **sheet tolerance** | The circle a leftover piece must fit inside. [`algorithms.md`](./algorithms.md) |
| **sheet remote** | The sheet with the border band removed. [`algorithms.md`](./algorithms.md) |
| **funnel** | Weed open at both ends. [`algorithms.md`](./algorithms.md) |
| **bucket** | Waste that closes to width zero. A cave is that bucket. [`algorithms.md`](./algorithms.md) |
| **ring** | The weed around one figure. [`algorithms.md`](./algorithms.md) |
| **loop** | The weed around one figure. [`algorithms.md`](./algorithms.md) |
| **radial corridor** | The weed around one figure. [`algorithms.md`](./algorithms.md) |
| **cavern allowance** | A threshold the person sets on a cavern measure the algorithms part names. [`algorithms.md`](./algorithms.md) |
| **Surround and Conquer** | The weed-line algorithm the window opens on. [`algorithms.md`](./algorithms.md) |
| **surround distance** | The clearance between the subject and a surround. [`algorithms.md`](./algorithms.md) |
| **surround** | The outer weed line. [`algorithms.md`](./algorithms.md) |
| **piece border** | The border rectangle, and the outer rectangle when the border has thickness. [`algorithms.md`](./algorithms.md) |
| **border rectangle** | The inner rectangle of the piece border. [`algorithms.md`](./algorithms.md) |
| **padding rectangle** | The piece size. [`algorithms.md`](./algorithms.md) |
| **border padding** | The gap from the piece size to the inner rectangle. [`algorithms.md`](./algorithms.md) |
| **border width** | The width of the piece-border strip. [`algorithms.md`](./algorithms.md) |
| **cluster** | The subject one surround encloses. [`algorithms.md`](./algorithms.md) |
| **join gap** | The length within which separate surrounds are joined. [`algorithms.md`](./algorithms.md) |
| **display unit** | The length unit the window shows. [`boundary.md`](./boundary.md) |
