frame. Start there runs the solver, and Apply returns the
weed-line color with the cuts. An untouched control is
`#FF0000`. A committed `#00aa00` is `#00AA00`. The path is not
empty. The untouched check also requires the layer `Weed lines`.

`_run_dialog` passes `defaults` through. The two color checks
pass `{'mode': 'frame'}`. A call that omits defaults still opens
on Surround and Conquer. The closed-window check does that and
still expects `(None, None, None)`.

The dialog and the surround step were not edited. Start on
Surround and Conquer still paints a surround, does not run a
solver, and does not enable Apply. An empty solver path still
leaves Apply disabled, so the dialog returns nothing.
