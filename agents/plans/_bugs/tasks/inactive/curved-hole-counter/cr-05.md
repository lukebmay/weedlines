# Curved hole counter

No defect remains in the change. The named checks passed.
An endpoint chord stands in for a cubic when that piece is
within 1e-6 of its curve and both controls project onto the
segment between its ends. A control past an end keeps that
piece splitting, so the extra length gets its own chord and
the side test runs there. A touch that stays on one side is
not a self-overlap.
