## Summary

`cache_dir` reads `WEEDLINES_CACHE_HOME` inside the
function on every call. A non-empty value is the
directory on Linux, Windows, and macOS, with no
`weedlines` suffix, and it wins over `XDG_CACHE_HOME`.
Unset or empty keeps the previous branch:
`XDG_CACHE_HOME/weedlines` on those platforms, otherwise
`~/.cache/weedlines`, `%LOCALAPPDATA%\weedlines\cache`
(or `~/weedlines/cache` when `LOCALAPPDATA` is unset),
and `~/Library/Caches/weedlines`. The directory is not
stored on the module.

Callers still ask `cache_dir` when they need a path.
`weedlines_ready.py`, `weedlines_svg.py`, and
`src/weedlines/install_ext.py` were not edited. No
config, data, state, or runtime home was added. The
guide was not edited. The runtime sentence still does
not name `WEEDLINES_CACHE_HOME`. That wait is the plan's
conflict, not a defect here.
