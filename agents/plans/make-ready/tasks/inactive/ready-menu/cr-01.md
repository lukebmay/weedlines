`write_correction_svg`, the same writer Make ready uses.
`Reimport last ready` already places that file. Leave
`last_result.svg` for a weed-line result. `Reimport last
weedlines` places that result. It refuses the ready file by
not reading `last_ready.svg`. It does not treat the window's
only copy, sitting in `last_result.svg`, as the ready file.
