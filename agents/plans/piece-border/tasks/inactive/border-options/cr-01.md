## Summary

The form shows Border Padding, Border Width, and Border
Rounded Corners in every mode. Border Corner Radius is
hidden while that box is off. The kept number starts at
one quarter of an inch: `_QUARTER_INCH` divided by the
document scale, the same count as the join gap. It is
not 6.35 and not a bare 0.25.

`lengths['border_radius']` holds that number for the
whole visit, including while the box is off.
`lengths['corner_radius']` is set only while the box is
on, and it is removed when the box is off. The spin
stops at zero and at half the shorter side of the inner
rectangle. A change to border padding runs that cap
again. Padding, the checkbox, and the radius ask for
the border and, when a surround is showing, for the
surround. Border width asks for the border only. A
committed change joins the option history. The form
does not build the rectangles.

`form.py` is 738 lines. The new code is the border
controls on the form that already owns the spins and
the history. It is not a separate responsibility. No
split.
