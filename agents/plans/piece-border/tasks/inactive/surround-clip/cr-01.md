# cr-01

One defect remains. The named check passed. Polygon surrounds
match the rule. A curved outline is cut into the subject.

## Summary

`build_surrounds` takes `inner_distance` after `join_gap`.
Omitted, or `None`, the outlines stay as they are and
`piece_border` is not called. A passed length, including
zero, clips each surround to the inner rectangle from
`piece_border(subject, inner_distance, 0.0)`. Sides of that
rectangle are left out of the run. A polyline that meets the
rectangle stays open, and the rest of it stays at the
surround distance. A surround that sits inside stays closed.
One the clip removes is absent.

The same clip then flattens curves. A distance-0 outline
that meets the inner rectangle is rebuilt from
`toSubpathPolygons()`. The chords lie inside the subject.

## Defect

`_clip_surround` in `src/weedlib/surround/build.py` intersects
the surround with the inner rectangle, then rebuilds every
run from `toSubpathPolygons()` with `lineTo` only.
`intersected` still has the curves. The polygon step
replaces them with chords.

Distance 0 is the subject's outer boundary. Inner distance
0 is that subject's bounding rectangle, so the boundary
meets it.

- A circle of diameter 20 becomes a closed 16-side polygon. The unclipped outline is the circle, 13 elements. `intersected` still has those curves. The polygon vertices sit on the circle. The chords do not. The closest sample is at radius 9.80, about 0.20 inside the subject.
- A rounded rectangle, 40 by 24, corner radius 6, correctly loses the straight sides that lie on the bounding rectangle. It keeps four open corner runs. Each run is four lines. The vertices sit on the arc. The chords do not. The closest sample is at radius 5.88 instead of 6, about 0.12 inside the corner. Every sample of those runs is inside the subject.

The rest of a run has to stay at least the surround
distance from the subject. At distance 0 that is the
outline, not a cut through the subject. The clip cuts the
subject.

A positive distance is already a polyline. A circle at
distance 5, clipped with inner distance 2, stays about
4.99 out, the same as the unclipped offset. The four
squares, the plus, a removed square, and a surround that
sits well inside all match the rule. The failure is the
flatten step.

## Remedy

In `src/weedlib/surround/build.py`, do not emit
`toSubpathPolygons()` as the cut.

Take the path `intersected` returns. Walk its elements. A
curve is one element: the curve-to and its data elements.
Drop an element only when the whole element lies on one
side of the inner rectangle. A line does when its ends
share a side. A curve does when its ends and its controls
do. Keep every other line and curve, in order, as an open
run. Do not close those runs. Do not replace a curve with
lines.

Judge the closing edge as well. If it lies on the
rectangle, leave it out. If it does not, it still joins
the two ends of that subpath.

If no element was dropped, return the original surround.
A curve that only touches the rectangle stays closed and
unchanged.

When every side of the intersection is the rectangle,
emit nothing. `piece_border` stays the only builder of
that rectangle. Do not edit `src/weedlib/piece_border.py`.

Add a test the current code fails. No Inkscape. Skip when
Qt cannot load. A circle at distance 0 and inner distance
0 stays the same closed path. A rounded rectangle at
distance 0 and inner distance 0 keeps each corner curve,
open, and samples of that curve are not inside the
subject. The four-squares test still passes.

## What held

Join, bridge, and smooth still run before the clip.
Island-hop is still there. The border width is not the
clip: the call is `piece_border(subject, inner_distance, 0.0)`
and the inner path is the one used. Open ends are not
moved back out to the surround distance. A polyline run
does not pick up the rectangle side between its ends.
More than one run follows that rule. The subject outline
is not substituted for a surround the clip removes.
`src/weedlib/solvers/` was not part of this change and was
not reviewed.

## Result

`toSubpathPolygons()`. Keep the curves `intersected`
already has, and drop only elements that lie on the inner
rectangle. `QT_QPA_PLATFORM=offscreen python3 -m pytest
tests/test_surround_clip.py`: 7 passed in 0.21s. No
Inkscape. `src/weedlib/piece_border.py` is unchanged.
