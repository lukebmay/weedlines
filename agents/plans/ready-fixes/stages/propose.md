# Propose

## This stage

The host part names the approval and the five kinds
of fix: stacked nodes on a smooth span, stacked nodes
on a corner, a larger self-overlap the person may
keep, overlapping figures welded into one path, and
a dangling end closed by joining its open ends.

The window shows the proposal. The library computes
the replacement path. The effect returns at once.
An approved set is the Ready fixes group in the
ready file. A decline leaves the arrow and the
original path.
