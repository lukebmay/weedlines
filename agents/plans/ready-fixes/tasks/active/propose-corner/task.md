# Propose corner

**Status:** ready

## Goal

Stacked nodes on a corner get the replacement the
host part names.

## Do

The rule is [the host part](../../../../../architecture/host.md).
Do not copy it.

`src/weedlib/propose.py` and `tests/test_propose.py`
only. The index lines already exist.

A corner stack that propose-span skips gets the
replacement the host part names for that case. Use
the proposal record and the defect order from that
task. Do not change the smooth-span replacement or
the larger self-overlap that has no path.

Do not start the join or the weld. Do not edit the
figure check, the arrows, the surround, the solvers,
the piece border, the surround clip, or the solver
clip. Do not call Inkscape. Do not edit the open
document. Do not seal a cavern, define conquer, or
emit a cut.

## Checks

- The corner fix matches the host part.
- Geometry tests do not need Inkscape.
