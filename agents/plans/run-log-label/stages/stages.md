# Stages

## This stage

The runtime part is the pane. The library reports the
stage it has entered, and a substage when it enters
one. The window appends one line for each report. It
does not append a line for each accepted segment.

The label is Algorithm output. Stdout and stderr
still arrive in the same pane. A verbose log level
may still record every accepted segment. Those lines
are not this pane's stage report.
