## Summary

The change fits the task. When a defect blocks Start and no
step is running or stopping, the button's tooltip names the
marked problems that are present. The words are the ones on
the defect line: dangling ends, figure overlaps, and
self-overlaps, in that order, joined the same way. The line
still carries the swatches. The tooltip does not.

`return_line.py` owns the list and the join.
`run_controls.py` asks it for the plain text and does not
keep a second list. The tip is set on every path that
enables or disables Start, including a border ask and
Clear All while a step is stopping. A border ask is not a
run, so the tip stays. Stopping clears it. A running step,
including Restart, leaves the tip empty and the status
working. A clear check leaves Start enabled with an empty
tip and the status ready. Conquer's Start is unchanged.
The defect line, the two return actions, and their place
under the preview are unchanged. The status words are
unchanged.
