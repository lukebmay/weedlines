## Summary

`docs/user/surround.md` tells a person, in the Start
section, that the window shows no time before the step
is started. After the step is started, it shows how long
that step has been working, with that step's status.
Pause holds the time, and Resume continues that run.
The time stays when the step is done. Restart starts
that time from zero. Clear All discards it with the
lines. Conquer is not given a time.

## Fit

The step-time sentences in `agents/architecture/runtime.md`
say the window shows the working time with the step's
status, holds it on Pause, keeps it when the step is
done, starts it from zero on Restart, and discards it
on Clear All. A step not started has no time. Conquer
has none while its Start stays disabled. The page says
that in checkboxes a person can do while reading. It
does not say the window owns the clock, and it does
not add a frame, grid, or island-hop procedure.
`agents/architecture/preview.md` is why the mode-change
box can stay where it is: leaving the mode clears the
lines, and returning after the step has been started
draws the surround again.
