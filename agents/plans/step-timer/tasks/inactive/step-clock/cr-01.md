# cr-01

No defects remain. The named checks passed.

## Summary

Each step row has a time label: `step-cut-time`,
`step-surround-time`, and `step-conquer-time`. The text is
empty until that step is started. A started step shows its
working time in seconds, to a tenth. The cut row shows the
time for the mode on screen. Frame, grid, and island-hop
each keep their own time. Conquer's label stays empty.

The window owns the clock. The time advances only while
that step's ask is working. Pause freezes the slice. A
finished step keeps the working time. Restart sets that
step back to zero and drops a later step's time. Clear All
drops every time. A border ask is not a working step, so
it does not advance one. The tick only rewrites the
labels. It does not ask, log, or repaint the preview. The
status text is unchanged. The library was not edited.

## Checks

- Before Start, and after the opening border ask goes idle, the three time labels are empty. Conquer's Start is disabled. Covered by `test_step_time_follows_the_run`.
- Frame's time leaves `0.0` while the status starts with working. The time text has no colon. A phase after `working: ` is not that text. The time is not a log line. Surround and conquer stay empty during that run.
- Pause keeps the same time text. The status starts with paused. Pumping the clock does not change `worker_calls`, the preview item count, or the log.
- After the step is done, that same time stays. The status is `done`. One `solver` call and no `surrounds` call. A later border-width change asks once and does not move the time or add a solver or surround call.
- Restart shows a smaller time than the finished one, then that time changes while the status starts with working. Conquer stays empty.
- Clear All leaves every time label empty and the status `ready`.
- Grid keeps its finished time across a frame run and a frame Restart. Frame's own Restart starts below its finished time. Covered by `test_another_mode_keeps_its_step_time`.

## Fit

The clock is a window timer. The library does not read it.
A working solver or surround ask is the only slice that
moves. Pause, finish, and a border ask freeze it. The
status stays ready, working, paused, or done, and a phase
name stays in that status. The time is on the step row.
