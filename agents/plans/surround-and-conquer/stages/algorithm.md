when the person starts it and the join gap. The window opens on
Surround and Conquer.

The host still writes the job first. The window is shown before
the figure check. Once it is up, the window asks for the check,
the subject, the weed area, and the arrow paths. The correction
groups stay labeled as the host part says. That analysis uses
the library calls that already exist. It does not grow a second
figure check.

Tasks for this stage follow those parts. Do not add a smoothing
control.

Any geometry this plan builds uses an efficient method. The
task note names the method. A slower method needs a reason.
That is a constraint on the task, not a survey of the repo.

User-visible steps for this stage belong in `docs/user/`. The
root README states the default mode, so that sentence changes
with this stage. It does not gain a longer guide.
