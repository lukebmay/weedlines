## Note

Open copies are not collapsed. `_dedupe_closed_subpaths` only
sees closed subpaths, which is the keep-fill collapse this task
says to call. Two copies of an open stroke stay two figures, and
each end is still a dangling defect. No named check uses an open
copy.

`_is_new_outline` treats a subpath as kept only when that helper
returns the same object. It does that today. A later copy inside
the helper would drop every closed figure.
