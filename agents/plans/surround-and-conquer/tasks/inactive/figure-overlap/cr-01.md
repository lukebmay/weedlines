# Figure overlap

Two defects remain. The named checks passed. Two preflight rules
have no test, and each can fail while this suite stays green.

## Defects

1. A self-overlap includes one subpath whose outline crosses
   itself. The suite only crosses two subpaths of one element
   (`_CROSS` and `_LENS`). Skipping every same-subpath segment
   pair leaves those tests green and reports no defect for a
   closed bowtie, `M 0,0 L 10,10 L 0,10 L 10,0 Z`, which crosses
   at (5, 5). Today's code reports `self-overlap` at that point.
   Remedy: add the test, and fix the code if the test fails.

2. The segment an open subpath is painted as if closed by is not
   a real border. No fixture makes that chord the only crossing.
   A square `M 0,0 L 4,0 L 4,4 L 0,4 Z` plus an open subpath
   `M -1,2 L -1,5 L 5,5 L 5,2` is one figure. The real segments
   do not cross. The painted chord from (5, 2) to (-1, 2) crosses
   the square at (0, 2) and (4, 2). Those are not self-overlaps,
   and the open ends stay dangling. Appending the chord to the
   border leaves the current tests green and reports both
   crossings. Today's code reports only the dangling ends at
   (-1, 2) and (5, 2). Remedy: add the test, and fix the code if
   the test fails.

## Summary

The change fits the task. `classify_figures` still takes only the
path records. One result can hold dangling ends, separate-figure
overlaps, and self-overlaps. It does not stop at the first. An
overlap target is a point in one connected shared area. Nesting,
a point touch, and a shared boundary with no area are not
overlaps. A counter whose real border does not cross stays out
of the interior. The lens where two subpaths cross stays in, so
that lens does not split one shared area. A self-overlap target
is a proper crossing of the real border. `src/weedlib/solvers.py`
is not edited. There is no subject or swap argument.

The code fits that change on the cases above. The defects are
the missing tests, not a wrong result from today's code.

## Note

The two-subpath fixtures never compare two segments of the same
subpath. No open fixture has a painted chord that crosses a real
border, so the dangling tests do not lock that exclusion. A
proper crossing rejects a shared endpoint, a T-junction, and a
collinear overlap. That matches "crosses" rather than a touch.
