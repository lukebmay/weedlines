# Figure overlap

No defects remain. The two missing tests from the previous pass
are in the suite. Each one fails if that rule regresses.
`src/weedlib/figures.py` was not changed for them.

## Summary

The added tests fit the two gaps. A closed bowtie
`M 0,0 L 10,10 L 0,10 L 10,0 Z` is one figure and one
self-overlap at (5, 5). Square `M 0,0 L 4,0 L 4,4 L 0,4 Z`
plus open `M -1,2 L -1,5 L 5,5 L 5,2` is one figure whose only
defects are dangling ends at (-1, 2) and (5, 2).

The current code matches those tests. The bowtie is one ring.
Its crossing is the two diagonals, which are not adjacent, so
same-subpath pairs are compared. The open subpath's polygon is
`(-1, 2), (-1, 5), (5, 5), (5, 2)`. That polygon does not repeat
the start, so the painted chord is not a border segment.

## Checks

- One subpath crossing itself is a self-overlap at the crossing.
  Covered by `test_one_subpath_bowtie_is_a_self_overlap`. It
  expects one figure and only `self-overlap` at (5, 5). Skipping
  every same-subpath segment pair makes this test fail.
- The painted closing chord is not a border. Covered by
  `test_painted_closing_chord_is_not_a_border`. It expects only
  dangling ends at (-1, 2) and (5, 2). Appending the chord from
  (5, 2) to (-1, 2) also reports self-overlaps at (0, 2) and
  (4, 2), and this test fails.
- `pytest tests/test_figures.py` passed: 10 passed, not skipped.
  Qt loaded. The tests do not load Inkscape.
- `src/weedlib/solvers.py` has no cut change. This has no test.
  `git diff --exit-code -- src/weedlib/solvers.py` is empty.

## Note

`_dangling` requires every defect to be a dangling end, so the
painted test rejects the extra crossings and not only a wrong
endpoint list. The open polygon never contains the chord, so the
pop of a repeated start is not what keeps this fixture clean.
