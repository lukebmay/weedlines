# cr-01

No defects remain. The named checks passed.

## Summary

The change fits the task. The job stores one record per path
element next to the existing `keep_d` and `doc_attrs`. `d` is in
document user units with that element's transform applied. A
closepath is written only when that subpath already had one.
Fill is `none`, `#rrggbb`, or `other`. The element's own opacity
of zero is `none`. Style wins over a presentation attribute, and
a solid fill is inherited. A path in a group labeled "Weedlines
corrections", or whose id starts with `weedlines-correction`, is
left out. `write_result` is unchanged, and `keep_d` is still the
union written with `close_subpaths=True`.

## Checks

- A stored open path has no added closepath, and the closed flags
  match the path data. Covered by
  `test_stored_open_path_has_no_added_closepath`. The first
  subpath stays open. The second keeps the source closepath.
- Fill none, opacity zero, a solid color, other paint, and an
  inherited solid color. Covered by `test_computed_fill_records`.
  Opacity zero is the element's own `opacity` attribute. The
  solid color is a style that beats `fill="none"`. The inherited
  color comes from the parent style.
- A corrections-group path and a `weedlines-correction` id are
  absent. Covered by `test_correction_paths_are_omitted`. The
  path nested under the labeled group is omitted, and the other
  path stays.
- `read_job` still returns `keep_d` and the document width,
  height, and viewBox. Covered by
  `test_read_job_returns_keep_d_and_document_size`.
- `pytest tests/test_job_records.py` passed: 4 passed. The test
  module does not import Inkscape.

## Note

Fill-opacity of zero and an ancestor opacity of zero are also
recorded as `none`. The test does not set either one. The host
part says opacity of zero is none, and it says to resolve style,
presentation attributes, and inheritance. It does not name
fill-opacity. Opacity is not an inherited property, so an
ancestor opacity is not that inheritance rule. The named opacity
check is the element's own opacity, and the test sets that. The
extra behavior is not a required host rule, so the missing
assertions are not a defect.
