# Review

Result: not accepted. Two defects. The named checks passed. The
positive-distance crossings are one smooth outline and stay within
the test rounding of the surround distance. Do not redo that path.

## Defects

1. Distance 0 and a positive join gap is not the outer boundary
   when the overlap is concave. In `build_surrounds`, join gap 0
   uses `_meeting_outers`. Any positive join gap uses
   `_outer_boundaries` and `_bridge_outlines`. The hull stitches
   the raw loops, so a union notch is replaced by a tangent.
   Squares at `(0, 0, 10, 10)` and `(5, 5, 10, 10)`, distance 0,
   join gap 0.1: the winding union is the stepped outline, area
   175, through `(10, 5)` and `(5, 10)`. The result drops those
   vertices, cuts `(10, 0)` to `(15, 5)` and `(5, 15)` to
   `(0, 10)`, and has area 200. The same cut happens at join gap
   6.35. A side-by-side overlap matches only because that union
   is the hull. Join gap 0 is still the union. A piece in a hole
   stays separate.

   Remedy: at distance 0, always take the outers from
   `_meeting_outers`, then let a positive join gap bridge only
   those outers. An overlap is already one boundary, so the hull
   must not see the raw loops. A near miss still joins. A piece
   in a hole stays its own group.

2. A near miss joins before the join gap reaches the separation.
   `_join_groups` dilates by `distance + join_gap / 2 + 0.01`.
   `_dilate` already scales by 32 and sets the stroker threshold
   to 0.01, and a circle's radial error is about 0.002. The extra
   0.01 is in user units, 0.02 on the separation. Straight
   surrounds whose separation is 1 join at join gap 0.980.
   Separation 0.015 joins at join gap 0.001. The comment that
   this is the curve flatness is wrong after the scale.

   Remedy: do not add `_CURVE_FLATNESS` in user units. Straight
   edges meet with no extra radius. If the diagonal case in
   `test_join_gap_unions_a_near_miss` then stays split at a join
   gap equal to the separation, the shortfall is the chord error,
   about 0.01 on that separation. Compensate with no more than
   that, and add a straight-edge check that a join gap 0.02 below
   the separation stays two outlines.
