## Summary

The change fits the task. On a clear Surround and Conquer design
the dialog is already visible before `classify_figures`, and
`build_surrounds` is not called while the spins are set, while
the mode changes, or while the person swaps, until Start
Algorithm. Start calls `build_surrounds(subject, distance,
join_gap)` and strokes those paths in the weed-line color, with
no fill, above the checkerboard. It does not call
`generate_weeds`, write a result, or enable Apply.

After that, a distance change, a join gap change, a swap, and
entering this mode again each call it. Change surround clears
the strokes, keeps both spin values, and does not call again
until the next Start. Leaving the mode clears the strokes and
keeps the values. A weed-line color change repaints and does not
clear the lines. The join gap control is `join-gap`, labeled
`Join gap (mm)`, shown only in this mode, starting at 6.35, and
it does not go below zero. The distance label is still
`Surround distance`. A defect still skips `build_surrounds` and
leaves Start disabled for every mode. Frame, grid, and
island-hop still cut.

`docs/user/surround.md` follows the wait, the two lengths,
Start, and Change surround, and it does not call Start an
approval. `src/weedlib/surround.py`, `README.md`, and
`docs/user/correction-arrows.md` have no diff. There is no
connector, smoothing control, conquer step, or second surround.
