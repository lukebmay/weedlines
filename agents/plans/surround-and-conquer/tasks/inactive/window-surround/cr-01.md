## Summary

The change fits the task. The mode list is Surround and Conquer,
then frame, grid, and island-hop. A missing mode, a blank mode, or
that name in any case opens on Surround and Conquer. `frame`,
`grid`, and `island-hop` open on those entries. Any other value
opens on frame.

On a clear design the preview strokes the paths
`build_surrounds(subject, distance)` returns, in the weed-line
color, with no fill, above the checkerboard. The distance control
is labeled "Surround distance" and is shown only in this mode, with
Change surround. It starts at five percent of the smaller side of
the design bounds, keeps a value set while the window is open, and
does not go below zero. A distance change, a swap, or entering the
mode asks the library again. Padding, spacing, and collar do not.

A defect paints no surround, does not call `build_surrounds`, and
leaves Start disabled in every mode. Start Algorithm in this mode
approves the lines on screen, leaves them up, and disables the
distance. It does not call `generate_weeds`, write a result, or
enable Apply. Change surround, swap, and a mode change clear that
approval. A weed-line color change repaints the lines and does not
clear it. Frame, grid, and island-hop still pass the subject to
`generate_weeds` and still cut.

`src/weedlib/`, `extensions/inkscape/weedlines.py`, `docs/`, and
`README.md` were not edited.
