dialog exists. A zero-timer runs after `exec_` has shown the
window. That pass calls `classify_figures` once, then
`subject_weed_regions` once for the current swap, then
`build_surrounds` once when the check is clear and the mode is
Surround and Conquer. `refresh_preview` then paints. It calls
`build_arrow_paths` once per defect kind that has targets, and it
does not call `build_surrounds`. `ready` runs after that. The
distance spin is updated with its signals blocked, so open does
not ask for the surround again.

before Start Algorithm. Start approves that preview and does not
run a solver. A defect does not call `build_surrounds`, Start
stays disabled, and the return line and the correction action are
already in the layout when `ready` runs. Later distance, swap,
and mode changes still ask. There is no new geometry method and
no second figure check. The open fight is not implemented: the
window does not wait for Start before the first surround, and the
surround geometry is unchanged.
