# Weedlib index

**Rank:** 3

**Stage:** index

## Goal

`src/weedlib/` has a directory index. Each source file
directly in that directory has one sentence for what it
owns. The subdirectory indexes stay where they are.

## Guide

The shape is the Source files section in
[`../../handbook.md`](../../handbook.md). This plan does
not change product behavior.

## Checks

- The index is at `src/weedlib/README.md`.
- Each source file directly in `src/weedlib/` appears
  once, with one sentence.
- `figures/README.md`, `solvers/README.md`, and
  `surround/README.md` stay the indexes of those
  directories. This plan does not restate them.
- No product code changes.
