## Summary

The change fits the task. Committed option edits share one
history on the dialog. It records the mode, the five lengths,
the output layer name, and the four preview colors. Ctrl+Z
undoes. Ctrl+Y and Ctrl+Shift+Z redo. There is no button.

A spin commits when its value changes. Keyboard tracking is
on, so each accepted number is that commit. Typing 2 and then
5 into the padding spin, without leaving the field, is two
entries. The first Ctrl+Z shows 2.0000 in the current unit.
The next shows the length from before those digits. The
spin's own line edit does not keep an undo back to that
earlier length. After those two digits its undo stops at
`2 mm` and is empty. The option history is what returns the
length. `setValue`, which the new test uses, is one commit.

A layer name or a color still being typed undoes in that
field and does not enter the history. It joins when the
field commits. Restoring a length goes through the existing
display conversion, so the person sees the current unit.
The library still receives document user units. Restoring
the mode shows that mode's knobs and does not clear a
surround or a cut.

Swap, the run controls, the log, and cuts are not entries.
Undo of a surround distance asks for that distance again, so
the lines match the restored length. It does not remove the
surround, and Apply stays disabled.
