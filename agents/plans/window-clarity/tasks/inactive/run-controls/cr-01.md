## Summary

The change fits the task. The window has one status and a
spinner. The run controls are Start, Restart, Pause, Clear
All, Apply, and Close. There is no Cancel button and no
Change surround button. The hint names Pause, Resume, and
Clear All. It does not name Cancel.

Frame, grid, and island-hop each show one step. One Start
button, object name `start`, sits on the step that can run.
It reads Start until that step has been started, then
Restart until Clear All. Restart stays disabled while the
step is running. It drops that step's lines and runs the
step again.

Surround and Conquer shows Surround, then Conquer. Surround
uses that same button. Conquer's Start, object name
`conquer-start`, stays disabled. The click handler returns
without a cut. A phase name from the library is written
into the one status as `working: <name>` or `paused: <name>`.
It does not add a step.

After the surround step the button reads Restart, the status
is done, and the spinner is hidden. That step asks the
surround child. It does not run a solver, and it does not
set a result. Apply stays off. An empty surround list uses
that same finish path: the step is done, nothing is
invented, and Apply stays off.

While a cut is running the status is working and the spinner
shows. Pause hides the spinner, does not clear the lines,
and Resume continues that same run. Clear All, including
from pause, drops the lines and the result immediately,
cancels the child, and does not kill it. The status is
ready and the button reads Start. The mode, the lengths,
swap, and the colors stay.

Close during a solver sets cancel and keeps pumping until
the next progress check, then rejects. It does not join the
child. The return is nothing. Close during any other ask
rejects immediately and does not join.

Geometry stays in the spawned child. The phase message is
sent from the solver hook in that child. The diff does not
touch the library. No progress call was added there.

The new rows make the size hint the whole window. On this
Qt the hint and the minimum height are 998, the open size
is 720 by 998, and the preview stays at its 180 minimum.
The return line sits under the preview and does not
intersect it. The splitter does not collapse the log or
the preview. That is the sizing the new rows need. It does
not hide the preview.
