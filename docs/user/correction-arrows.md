# Place correction arrows

Weed lines will not run until you correct the marked problems
in Inkscape.

These steps apply when a line under the preview names problems.
If that line is empty, weed lines can run. **Return to Inkscape
with correction arrows** is not shown, and there is nothing to
import.

## Read the line

- [ ] Read the line under the preview. It says to correct the
  marked problems in Inkscape before weed lines will run, and
  it names each kind that is present: dangling ends, figure
  overlaps, and self-overlaps.

## Send the arrows

- [ ] Choose **Return to Inkscape with correction arrows**. The
  line changes to "Run Extensions → Weedlines → Import last
  result to place the arrows." The window stays open.
- [ ] Choose **Return to Inkscape**. The window closes.
- [ ] In Inkscape, choose **Extensions → Weedlines → Import last
  result**.
- [ ] In the Layers panel, find the new layer **Weedlines
  corrections** above the rest of the document. It holds a group
  for each kind that has an arrow, and only those kinds:
  **Dangling ends**, **Figure overlaps**, and **Self-overlaps**.
- [ ] Confirm your own paths are unchanged. Import does not add a
  copy of the design, and it does not delete or rewrite them.

## Leave without placing arrows

- [ ] Choose **Return to Inkscape**. The window closes. No arrows
  are written, and there is nothing to import.
