# Approve the surround

The window opens on Surround and Conquer. The surround on
screen is a preview until you approve it.

## Open the window

- [ ] In Inkscape, choose **Extensions → Weedlines → Weedlines
  from selection…**. The window opens on **Surround and
  Conquer**.

## Read the line

- [ ] Read the line under the preview. When it names problems,
  no surround is shown and Start stays off. Follow
  [Place correction arrows](correction-arrows.md). When that
  line is empty, continue.

## Set the distance

- [ ] Find **Surround distance**. It is on the form only while
  the mode is Surround and Conquer. Until you set a number, it
  is five percent of the shorter side of the box around the
  design. The window keeps your number while it stays open.
- [ ] Change the number to set the clearance between the subject
  and the surround. The subject is the region you are keeping.
  The number cannot go below zero. Zero is the outer boundary
  of the subject. It is a length in the document's units.
- [ ] Watch the preview. The surround is drawn in the **Weed
  line color**, on top of the checkerboard, and it follows the
  distance. **Swap subject and weed area** updates it too.

Padding, grid spacing, the collar, and the output layer do not
change the surround.

## Approve

- [ ] Choose **Start Algorithm**. That approves the surround
  that is showing. The approval does not write a result. The
  lines stay up, and **Surround distance** is disabled.

## Change the surround

- [ ] Choose **Change surround**. That clears the approval and
  lets you edit **Surround distance** again. The number stays,
  and the preview follows it.

**Swap subject and weed area**, or a change to another mode,
also clears an approval.
