# figures

- `__init__.py` re-exports the figure-check names callers already use.
- `types.py` holds the four figure-check records.
- `check.py` classifies figures, collapses twins, and names dangling ends and subject area.
- `overlap.py` reports one defect for each connected shared area.
- `interior.py` holds sample points and area tests.
- `borders.py` holds self-overlap and the cubic hit test.
